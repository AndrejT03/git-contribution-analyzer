How it works

Four stages, from raw Git history to a report you can read and share.

  1. Step 1

    Read Git history

    Clone commits, authors, and diffs from the public repository.

  2. Step 2

    Analyze contributions

    Gemini classifies each commit, with a deterministic local fallback.

  3. Step 3

    Build the browser report

    A detailed, scannable report opens right here in your browser.

  4. Step 4

    Attempt email delivery

    A secondary copy is sent to your inbox whenever possible.
